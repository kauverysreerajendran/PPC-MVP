1. Introduction

Watch cases sent to vendors for polishing and plating come back to Titan CBE, where the PPC and Stores teams verify them against the delivery challan, count the pieces and look for rack space by hand.

PPC-WIM digitises this inward flow. Each dispatched lot gets a Box UID, the returned box is scanned to verify it against its SAP outward line, and its exact rack, shelf, row and tray position is recorded so it can be found later without searching.

2. DFD and Workflow - Process 6, 17, 18

The inward DFD has 19 processes. The MVP covers the three highlighted below.

P1 - P5 Receive and security→P6 Verify DC / reference→P7 - P16 SAP 101, 321, 313→P17 Move to CBFC rack→P18 Rack - Row - Bin mapping→P19 Stored in DB

Process 6 - Verify received box (SAP Inward screen)

Scan Box UID→Match SAP outward line (PO, DC, model, qty)→Count pieces per scan→RECEIVED / SHORT / OVER

Process 17 - Move to CBFC rack (Rack Locator)

Select warehouse and aisle→Locate empty trays→Choose rack→Occupy tray with model / lot

Process 18 - Rack, Row, Bin mapping (Rack Locator)

Open rack→Shelf, row, tray grid→Tray code, e.g. K-S4-R2-T05→Find by model or code
